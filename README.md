# Threebody.space

**https://threebody.space** · 源码 <https://github.com/AyagawaSeirin/Threebody.space>

《三体》与《我的三体》的粉丝站。单页长滚动叙事 + 423 条书摘。
需求源是 `docs/BRIEF.md`。视觉规范是照 kill-ai-slop 那 35 条 tell 反向写的
（不是做完再扫，是一开始就不写出来）。交付时全项目 0 命中，之后 skill 已从仓库移除，
源码里留下的 9 处 `deslop-ignore-next-line` 注释记录了当时逐条确认过的例外及理由。

## 跑起来

```bash
npm install
npm run dev        # 开发
npm run build      # 类型检查 + 产物
npm run preview    # 实机看
```

## 在线预览

```bash
npm run build && npm run serve      # 默认 4180，局域网同一 WiFi 的手机也能开
npm run serve -- --port 8080        # 换端口
npm run serve -- --local            # 只听 127.0.0.1，不对局域网开放
```

`scripts/serve.mjs` 是零依赖的静态服务器（node 内置 http），做两件正经事：
把 `/sentences` 这类路径回退到 `index.html`（否则刷新就是 404），
以及给带哈希的产物长缓存、给 HTML 不缓存。路径穿越已挡（`../` 一律回退，不会读到 dist 之外）。

部署到任意静态托管同理，只要配一条 SPA 回退规则。

### 单文件版

```bash
npm run build:standalone            # → dist-standalone/index.html
```

图片（三套格式）和 423 条书摘全部内联成 data: URI，JS/CSS 也内联，
产出一个 3.5MB 的自包含 HTML，双击就能看，不需要服务器。
这一版走 hash 路由（`#/sentences`），因为没有服务端做回退。
站点代码不为此分叉：资源地址统一走 `src/content/assets.ts` 解析。

## 维护脚本

```bash
npm run sentences  # 用 .cache/ 重建书摘数据（逐字节可复现）
npm run images     # 从 .cache/images-orig/ 重压 AVIF+WebP+JPG
npm run typecheck
```

补图或重做素材：`node scripts/gen-images.mjs <name>`（需要 `.env.imagegen.local`）。

## 几个绕不过去的决定

**颜色只有五个值**，都在 `src/styles/tokens.css`。背景永远是纯黑，没有第二种底色，
没有氛围光晕，没有卡片表面渐变。

`--signal` 红只表示「人类发出去的信号 / 收不回的决定」，全站预算 5 处，
当前用了 4 处：红岸那盏灯、「1971」、「威慑纪元 62」、「掩体纪元 67」。
它从 `#c8352b` 提到了 `#d4453a` —— 原值 on 黑只有 4.00:1，14px 的纪年不够 4.5:1。

**站点标记是算出来的，不是画出来的。** `scripts/gen-mark.mjs` 跑一遍速度 Verlet 积分，
采样 Chenciner–Montgomery 的 8 字三体周期解，输出 SVG path；
`SiteMark.vue` 和 `public/favicon.svg` 共用这条路径（改标记时两处一起换，脚本会提示）。
和页面上那个模拟器同源，区别只有一处：标记不加扰动，所以曲线闭合、每次生成都一样
（logo 不能每次编译都变形）；模拟器要展示「无法长期预测」，必须扰动。

取景转了 90° 并让两轴各自拉满方框——8 字解本身长宽比约 3:1，等比塞进方框只有 7 个单位高，
26px 的导航里就是一团糊掉的 ∞。favicon 另调了一份参数（线加粗到 2.6、方点缩小），
因为 16px 标签页里 1.4 的线不到一个物理像素，会整条消失，只剩三个点像三条横杠。

**年表的公元年份是推算，标了「约」。** 原著没有直接写明任何纪元元年对应公元哪一年。
换算只用一个依据：书中汪淼见到叶文洁是 1969 年的三十八年后，即公元 2007 年，那年是危机纪元元年；
其余纪元按各自跨度顺推，所以整张表内部自洽。它和网上流传的几种时间线会差几年
（常见的另一套把威慑纪元起点放在 2208 年），差异来自纪元首尾年是否共享，原著没写，谁也补不出来。
页面上这一列比纪年弱一档，但没有用 opacity 压——`--ink-1` 乘 0.72 会掉到 3.48:1，
14px 正文不到 4.5:1，所以改用括号和措辞做层级。

**字体走系统栈，不加载 webfont。** 一套中文字重好几 MB，为首屏下它不值得；
Songti SC / 宋体 / SimSun 本身就是这套书该有的样子。标题黑体、正文宋体是中文出版的常规分工。
等宽只给年份、量级、坐标这类真数据，不给按钮标签导航。

**书摘正文不进 bundle。** `src/content/sentences.json`（156KB）由 `scripts/sync-data.mjs`
同步到 `public/data/`，运行时 fetch。`scripts/sync-data.mjs` 会核对条数——
文案里有六处写着「423 条」，数据一旦变了就直接构建失败，不让数字悄悄对不上。

**三体运动是真在算的。** `ThreeBodyCanvas.vue` 用速度 Verlet 积分牛顿引力。
构型是「自由落体三体」：三个质点摆成不规则三角形、从静止释放——经典的混沌构型，
近距交会、甩摆、突然变向，没有任何周期性。混沌的必然结局是某个质点迟早被甩出系统，
这不回避也不掩饰（书里三体世界的行星就是这样被抛来抛去的）：质点越出逃逸半径后画面淡出，
换一组初值重新开始一局。初值种子池用数值试验筛过，只留能撑约半分钟到两分钟才逃逸的局
（400 局统计里约三分之一合格）；近距交会用 0.15 的引力软化兜住，最坏能量漂移 6.5e-4。
早期版本用的是 8 字周期解加 7% 扰动，画面太规律像编排好的舞蹈，被站主打回重做——
现在站点标记（logo）仍保留那条 8 字轨道，因为 logo 恰恰需要闭合与稳定。

**图注不重复 alt。** 画面描述只写在 `alt` 里给读屏软件用，不再作为图注显示——
把「山脊上一座巨大的射电望远镜剪影……」印在图下面，是让眼睛能看见的人再读一遍他已经看到的东西。

**站内数字都能说出出处。** 四季的集数与日期来自公开报道；评分取自哔哩哔哩番剧页与豆瓣条目，
页面上注明了查询日期。年表沿用原著纪年、不换算公元——原著没给危机纪元元年对应哪一年，
民间时间线互相矛盾，换算出来就是查不到出处的数。播放量、粉丝数、制作费用一个都没有。

**没有署名的 395 条下面什么都不加。** 原始数据里没有出处信息，补什么都是编的。

## deslop 扫描

`npm run deslop` 应当 0 命中。源码里有 8 处 `deslop-ignore-next-line`，都带 id 和理由：

| 位置 | tell | 理由 |
|---|---|---|
| `tokens.css`、`base.css`、`SentencesView.vue` | 07 08 | 正文宋体是编排型内容的正解，不是「serif = 高级」 |
| `tokens.css`、`type.css` | 34 | 等宽只用在真数据上，UI chrome 一律黑体 |
| `SectionDarkForest.vue` | 06 | 那是光针本身两端的渐隐，不是氛围打光 |
| `SentenceItem.vue` ×2 | 09 13 | 检索命中的真实标注：无背景色，只加重字重 |

## 已验证

浏览器实测，不只是跑脚本：

- 四个页面 0 对比度失败（正文 18.7:1，次要文字 6.1:1，signal 4.7:1）。
  开场白字压在图上也量过原图像素：那片区域最亮 rgb(7,7,7)，17.97:1，所以没有加暗色蒙版。
- 红灯方点与黑暗森林那根光针的位置是从素材像素实测出来的（72.47%/36.53%、33.07%），
  运行时校验偏差 ≤1px。
- 减弱动态效果：位移全关，水滴锁在 scale(1)，Canvas 只画一帧静态图，27 个进场块全部可见。
- 375px：尺度尺转竖向可拖可读，无横向滚动。
- 尺度尺键盘可达（7 次 Tab），Shift+方向键正好跨一个数量级，焦点框 1px 不发光。
- 书摘分批追加 12 → 24 → 36 → 48 → 60；检索命中 10/423；无结果是一句正常的话。
- 圆角盒子共 2 个，描边和圆角都在同一元素上；无 glassmorphism、无大投影、无卡片网格。
- 单张图片 ≤192KB；首屏 JS gzip 约 42KB。
- 章节配图有高度上限（宽屏 62vh / 窄屏 52vh）：3:2 素材在高窗口里按原比例铺满宽度
  会超过一屏，把标题和正文整个顶出首屏。8 种视口 × 4 个页面实测无横向溢出。
- 开场首屏在 320×568 到 1920×1080 之间都完整：三颗星、标题、说明、剧透提示同屏。
- 单文件版在 `file://` 下实测四个路由全部可用，零外部请求、零报错，8 张图全部加载。
- 站点标记在 26px 导航与 16/20/32px 标签页三档下逐一看过；标记路径闭合误差 0.022（viewBox 单位）。
